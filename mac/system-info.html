Local macOS System Inventory

System Info

System Info is a local-only macOS information collector that records operating-system, hardware, display, storage, network, power, security-state, update-history, and process information into a Desktop text report.

Installation

Using the Melding Software Mac installer

The Melding Software homepage provides this Terminal installer command:

curl -fsSL https://raw.githubusercontent.com/MeldingSoftware/Scripts/main/Mac/install.sh | bash

Because this command downloads and immediately runs a shell installer, you can review install.sh in the GitHub repository before executing it. Individual scripts may also request permissions, administrator access, Keychain authorization, Full Disk Access, or other macOS approvals depending on what the selected tool needs.

Documentation

System and hardware

Computer names

Collects ComputerName, HostName, and LocalHostName where available.

Operating system

Records sw_vers, kernel/architecture, uptime, and boot time.

Hardware

Uses system_profiler hardware data plus sysctl CPU and memory information.

Graphics

Collects display/GPU details from SPDisplaysDataType.

Documentation

Storage and network

Storage

Collects system_profiler storage data, diskutil list, and APFS volume information.

Network ports

Lists hardware network ports.

Active route

Determines the default network interface and attempts to display its IP address.

DNS and routes

Captures scutil --dns and netstat -rn.

Wi-Fi status

Uses Apple's airport utility when that binary exists.

Documentation

Power and security checks

Battery/power

Captures pmset battery status, AppleSmartBattery information, and SPPowerDataType output.

Gatekeeper

Records spctl --status.

FileVault

Records fdesetup status.

SIP

Records csrutil status.

Firewall

Reads the Application Firewall preference when the expected plist exists.

Documentation

Updates, processes, and output

Update history

Includes up to the first 100 lines of softwareupdate --history.

Top CPU processes

Captures a lightweight top-15 snapshot sorted by CPU use.

Local-only report

Writes to ~/Desktop/System Info Results/System Info.txt, falling back to the user's home directory if Desktop is unavailable.

No external upload

The script contains no curl, web API, or upload path.

FAQ

Frequently asked questions

Is the report sent anywhere?

No. This version is explicitly local-only.

Does it include battery data?

Yes, using pmset, ioreg, and system_profiler where available.

Does it show security settings?

It records quick status checks for Gatekeeper, FileVault, SIP, and the Application Firewall.

Where is the report saved?

Normally in Desktop/System Info Results/System Info.txt.
