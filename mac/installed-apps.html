macOS Application Inventory

Installed Apps

Installed Apps creates a simple text inventory of application bundles found in the standard user-facing macOS application directories.

Installation

Using the Melding Software Mac installer

The Melding Software homepage provides this Terminal installer command:

curl -fsSL https://raw.githubusercontent.com/MeldingSoftware/Scripts/main/Mac/install.sh | bash

Because this command downloads and immediately runs a shell installer, you can review install.sh in the GitHub repository before executing it. Individual scripts may also request permissions, administrator access, Keychain authorization, Full Disk Access, or other macOS approvals depending on what the selected tool needs.

Documentation

Application sources

/Applications

Lists application names installed in the standard Applications folder.

/System/Applications

Adds Apple's built-in system application names from the protected system Applications folder.

Documentation

Output

Desktop report

Writes the combined list to ~/Desktop/Installed_Applications_List.txt.

Plain-text format

The report begins with an Installed Applications heading followed by the application names returned by the two directory listings.

Replaced on the next run

The output file is written fresh rather than appended to indefinitely.

Documentation

Scope

Application names only

The script does not collect application versions, bundle identifiers, install dates, licenses, or package receipts.

No changes

It does not install, remove, update, or launch applications.

No network activity

The script contains no web requests or uploads.

FAQ

Frequently asked questions

Where is the list saved?

On the current user's Desktop as Installed_Applications_List.txt.

Does it include Apple system apps?

Yes. It adds names from /System/Applications.

Does it include apps installed elsewhere?

Not in the current version; it lists /Applications and /System/Applications.

Does it modify any apps?

No. It only reads directory contents and writes a text file.
