macOS Application Cleanup

DeBloater

DeBloater is a conservative macOS cleanup script that attempts to remove a small, predefined list of normally removable applications from /Applications while leaving SIP-protected system applications alone.

Installation

Using the Melding Software Mac installer

Copy and paste this command into Terminal to install the Melding Software Mac scripts.

After reopening Terminal, type MeldingSoftware anytime to load the list.

curl -fsSL https://raw.githubusercontent.com/MeldingSoftware/Scripts/main/Mac/install.sh | bash

Because this command downloads and immediately runs a shell installer, you can review install.sh in the GitHub repository before executing it. Individual scripts may also request permissions, administrator access, Keychain authorization, Full Disk Access, or other macOS approvals depending on what the selected tool needs.

Documentation

What it targets

Curated application list

The current list includes iMovie, GarageBand, Keynote, Numbers, Pages, Clips, and Xcode when those apps are present in /Applications.

Protected apps are skipped

If a matching app exists under /System/Applications, the script labels it as SIP-protected and does not attempt to remove it.

Running apps

Before removal, the script asks the application to quit through AppleScript when possible.

No sudo by design

The script intentionally runs with normal user permissions. Apps that require stronger permissions may fail to delete and are reported as errors.

Documentation

How removal works

Application bundle deletion

For an app found under /Applications, the script uses rm -rf on that application bundle.

No hidden system changes

It does not disable SIP, alter Recovery settings, edit system policy, or remove protected /System/Applications content.

Summary counters

At the end it reports how many targets were removed, not found, or identified as protected.

Documentation

Important limitations

Not a universal uninstaller

The script removes the selected .app bundles only. It does not search every Library folder for application support files, preferences, caches, or login items.

Permissions can block deletion

Some /Applications items may require administrator authorization. This version does not elevate itself, so those removals can fail.

SIP remains enabled

The script explicitly avoids protected system apps rather than asking the user to weaken System Integrity Protection.

FAQ

Frequently asked questions

Does it disable SIP?

No. It explicitly skips protected /System/Applications content.

Which apps can it remove?

The current built-in list targets iMovie, GarageBand, Keynote, Numbers, Pages, Clips, and Xcode when found in /Applications.

Does it remove leftover support files?

No. The current version focuses on deleting the selected application bundles.

Does it require an internet connection?

No. The current script contains no web request or download logic.
