macOS Printing Service Restart

Print Spooler Fix

Print Spooler Fix is a minimal shell script that restarts the macOS CUPS printing daemon when printing is stuck or the spooler needs a quick service reset.

Installation

Using the Melding Software Mac installer

The Melding Software homepage provides this Terminal installer command:

curl -fsSL https://raw.githubusercontent.com/MeldingSoftware/Scripts/main/Mac/install.sh | bash

Because this command downloads and immediately runs a shell installer, you can review install.sh in the GitHub repository before executing it. Individual scripts may also request permissions, administrator access, Keychain authorization, Full Disk Access, or other macOS approvals depending on what the selected tool needs.

Documentation

Repair sequence

Stop CUPS

Runs sudo launchctl stop org.cups.cupsd.

Wait

Pauses for five seconds after the stop request.

Start CUPS

Runs sudo launchctl start org.cups.cupsd.

Completion message

Prints a confirmation that the print spooler has been restarted.

Documentation

What it does not do

No queue-file deletion

Unlike some Windows spooler fixes, this script does not delete print-job files.

No printer removal

It does not remove printers, queues, drivers, or printer preferences.

No network requests

There is no download, API, or upload behavior.

Documentation

Compatibility note

Service-label dependent

The current version specifically targets the launchd label org.cups.cupsd. Behavior depends on that service label being available on the macOS version in use.

FAQ

Frequently asked questions

Does it erase queued print jobs?

No. The current script only stops and starts the CUPS daemon.

Does it need administrator authorization?

Yes. Both launchctl commands are invoked with sudo.

How long does it wait?

Five seconds between stopping and starting the service.

Does it reinstall printer drivers?

No.
