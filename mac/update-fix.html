macOS Software Update Reset

Update Fix

Update Fix resets selected local macOS Software Update state by stopping the update service/processes, clearing removable contents under /Library/Updates, then restarting the software update service.

Important: The script contains troubleshooting guidance for files protected by SIP/system-immutable flags. Disabling System Integrity Protection reduces macOS security and is not performed automatically by the script. Avoid disabling SIP unless you understand the implications and have a specific recovery reason.

Installation

Using the Melding Software Mac installer

The Melding Software homepage provides this Terminal installer command:

Individual scripts may also request permissions, administrator access, Keychain authorization, Full Disk Access, or other macOS approvals depending on what the selected tool needs.

Documentation

Service reset

Stops update service

Attempts launchctl bootout for com.apple.softwareupdate and terminates softwareupdated/softwareupdate processes.

Version-tolerant behavior

Stop commands ignore errors so the script can continue across macOS versions where service behavior differs.

Restarts update service

Uses launchctl bootstrap followed by kickstart against the software update service plist.

Documentation

Update cache cleanup

/Library/Updates

Ensures the directory exists, displays its state, clears immutable flags where permitted, and removes contents that macOS allows.

Metadata plists

Specifically attempts to remove index.plist and ProductMetadata.plist.

Protected files

If those files remain, the script explains that system-immutable flags or SIP/rootless protections may be responsible.

Documentation

What the script does not do

No automatic SIP change

It only prints Recovery commands as an advanced troubleshooting option; it does not run csrutil itself.

No OS reinstall

The script does not reinstall macOS.

No automatic reboot

It recommends rebooting if Software Update remains stuck but does not restart the Mac itself.

FAQ

Frequently asked questions

What folder does it clear?

/Library/Updates.

Does it stop the update service first?

Yes. It attempts to stop the launch daemon and software update processes.

Does it disable SIP?

No. It can print instructions discussing SIP for stubborn protected files, but it does not execute csrutil.

What should I do after it completes?

If Software Update is still stuck, the script suggests rebooting once.
