# Melding Software Website

Official website for **Melding Software**, featuring free and open-source utilities for Windows and macOS.

🌐 **Website:** https://meldingsoftware.com  
💻 **Scripts:** https://github.com/MeldingSoftware/Scripts

## About

Melding Software provides free and open-source Windows and macOS utilities designed to simplify setup, maintenance, troubleshooting, diagnostics, repair, automation, and everyday computing.

The website provides direct access to Windows downloads, macOS installation instructions, screenshots, and detailed documentation explaining what each tool does, how it works, its requirements, and what changes it may make to a system.

## Repository Contents

- `index.html` — Main Melding Software website
- `privacy.html` — Privacy Policy
- `legal.html` — License, disclaimer, and legal information
- `styles.css` — Website styling and responsive layout
- `javascript.js` — Website navigation, galleries, copy controls, and other interactivity
- `windows/` — Detailed documentation pages for Windows utilities
- `mac/` — Detailed documentation pages for macOS utilities
- `images/` — Logos, screenshots, QR codes, and other visual assets
- `favicon.ico` — Website favicon
- `ads.txt` — Authorized digital advertising seller information
- `robots.txt` — Search engine crawler instructions
- `sitemap.xml` — Sitemap containing the website's public pages
- `CNAME` — Custom domain configuration for GitHub Pages
