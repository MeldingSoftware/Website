Windows Wi-Fi Utility

Wi-Fi Info

Wi-Fi Info is a lightweight PowerShell utility that reads the Wi-Fi profiles already saved in the local Windows installation, displays their SSID names and any locally stored passwords Windows can reveal, and saves the results to a text file beside the script.

Workflow

How Wi-Fi Info works

01List Saved Profiles
02Read Stored Keys
03Display & Save

Saved Profiles

Enumerates Windows WLAN profiles

The script begins with the built-in Windows command netsh wlan show profiles. It extracts entries labeled All User Profile and treats each returned profile name as an SSID/profile to inspect.

Wi-Fi Info does not scan nearby wireless networks. It works from Wi-Fi profiles that Windows has already saved on the computer.

Password Retrieval

Requests stored Wi-Fi keys in clear text

For each saved profile, the current script runs:

netsh wlan show profile name="PROFILE_NAME" key=clear

It then searches the returned profile details for Key Content. When Windows exposes a stored wireless key, that value becomes the PASSWORD field associated with the SSID.

SSID

The profile name extracted from Windows is stored in the SSID column.

Password

The value found after Key Content is stored in the PASSWORD column.

Not every saved profile necessarily has a retrievable password. Open networks, enterprise-authenticated networks, profiles without a stored key, or profiles Windows cannot reveal may result in a blank password field.

Console Output

SSID and password table

When profiles are found, the collected objects are formatted into a PowerShell table with SSID and PASSWORD columns. If no saved Wi-Fi profiles are detected, the script displays:

No Wi-Fi profiles found on this computer.

Saved Results

Wifi Info.txt

After collecting the profile information, the script writes the same data to:

<script directory>\Wifi Info.txt

Saved beside the script

The destination is based on PowerShell's $PSScriptRoot, so the text file is created in the extracted Wi-Fi Info folder.

ASCII text output

The current script writes the results with Out-File -Encoding ASCII.

Replaced on another run

The script does not use -Append, so another run writes a new Wifi Info.txt at the same location.

Local file only

The current script contains no command that uploads or transmits the generated text file.

How To Run

Launching Wi-Fi Info

  1. Use the utility only on a computer you own or are authorized to manage.
  2. Download and extract Wi-Fi Info.zip.
  3. Run Run Me.bat.
  4. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC.
  5. Windows saved Wi-Fi profiles are enumerated.
  6. Each profile is queried with key=clear so any locally stored key can be read.
  7. The SSID/password table is displayed in the console.
  8. The results are written to Wifi Info.txt beside the script.
  9. Press Enter to exit.
The included Read Me notes that Windows 11 may display a “Windows protected your PC” SmartScreen message because the script was downloaded. Review the files before choosing “More info” and “Run anyway.”

Transparency

What the current script does and does not do

Reads local Windows profiles

The information comes from WLAN profiles already stored by Windows on the computer.

Does not discover remote passwords

The script does not crack Wi-Fi encryption or obtain passwords from networks that are not already represented by saved Windows profiles.

No network requests

The current PowerShell script contains no web request, API request, upload, or download logic.

No persistent installation

It does not install a service, scheduled task, startup item, or other background component.

FAQ

Frequently asked questions

What Wi-Fi networks does it show?

Profiles already saved in Windows and returned as All User Profile entries by netsh wlan show profiles.

Can it display saved Wi-Fi passwords?

Yes. It requests each profile with key=clear and records the Key Content value when Windows provides one.

Why might a password be blank?

The network may not use a stored pre-shared key, or Windows may not return a Key Content value for that profile.

Where is the result saved?

As Wifi Info.txt in the same directory as Wi-Fi Info.ps1.

Does it send the passwords anywhere?

No. The current script contains no network or upload functionality.

Does it require administrator access?

The included batch launcher requests administrator elevation through UAC before running the PowerShell script.
