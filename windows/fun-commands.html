Included Tools

What is inside Fun Commands

The ZIP is organized into separate folders so each feature can be used independently. Nothing in the current package installs a background service or startup task.

Cat Fact

Connects to catfact.ninja with PowerShell, retrieves one random cat fact, prints it in the console, and speaks it using the Windows Microsoft Zira Desktop voice through System.Speech.

Internet connection required.

Matrix

Draws a continuously moving Matrix-style stream of symbols in the PowerShell console using randomized glyph positions, ANSI color sequences, and console cursor positioning.

Press any key to stop the animation.

Songs

Contains individual PowerShell scripts that play recognizable melodies through System.Console.Beep. Each song is stored as its own .ps1 file and can be launched separately.

Uses the computer's console-beep support.

Text To Speech

Uses Windows SAPI to enumerate the speech voices installed on the PC. You choose a voice, enter English text, and the tool speaks it. The prompt repeats until you type exit.

Available voices depend on Windows.

Five included console songs

How To Run

Launching the included tools

Cat Fact, Matrix, and Text To Speech

Each of these folders includes a Run Me.bat launcher. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC with -Verb RunAs.

Songs

The Songs folder does not contain a batch launcher. Run the individual song .ps1 file directly with PowerShell when you want to play that melody.

  1. Download and extract Fun Commands.zip.
  2. Open the folder for the feature you want to use.
  3. For Cat Fact, Matrix, or Text To Speech, run Run Me.bat and approve the UAC prompt if you want to continue.
  4. For Songs, choose one of the included PowerShell song files and run it with PowerShell.

Transparency

What each feature accesses

Network access

Cat Fact is the only current feature that performs a web request. It requests a random fact from https://catfact.ninja/fact. Matrix, Songs, and Text To Speech operate locally.

Speech services

Cat Fact loads the Windows System.Speech assembly and selects Microsoft Zira Desktop. Text To Speech uses the Windows SAPI.SPVoice COM interface and lists the voices installed on the PC.

Console output

Matrix changes console colors, hides the cursor while running, and restores the original foreground/background colors when it exits. Songs use console beep frequencies and timing.

No persistent installation

The scripts in the current ZIP do not contain code to install a Windows service, create a scheduled task, add a startup entry, or persist after the command finishes.

The included Read Me files note that Windows 11 may show a “Windows protected your PC” SmartScreen message because the scripts were downloaded. Review the files and source before choosing to run downloaded scripts.

Matrix Notes

PowerShell 5 folder-name limitation

The Matrix script includes a note about a PowerShell 5 issue when a script is launched from a folder whose path contains an apostrophe. If Matrix does not start under PowerShell 5 and the folder path contains an apostrophe, move the extracted folder to a path without one and run it again.

FAQ

Frequently asked questions

Are Games and Prank included?

No. The current Fun Commands ZIP contains Cat Fact, Matrix, Songs, and Text To Speech.

Does Cat Fact require the internet?

Yes. It retrieves its fact from catfact.ninja before displaying and speaking it.

How do I stop Matrix?

Press any key. The script then restores the console foreground and background colors and clears the screen.

Can Text To Speech use different voices?

Yes. It lists the SAPI voices available on the PC and asks you to choose one by number before speaking text.

How do I exit Text To Speech?

Type exit when prompted for text.

Do the songs play MP3 or WAV files?

No. The included song scripts create their melodies using timed System.Console.Beep calls.
