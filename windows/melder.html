WinGet & App Installer

Built-in dependency and App Installer repair

Melder depends heavily on Windows Package Manager. If App Installer is missing or too old, the script can repair the required components before the GUI is used.

Bundled AppX dependencies

The ZIP includes Microsoft VCLibs and Microsoft UI Xaml AppX packages used by the App Installer repair path.

Windows App Runtime 1.8

Melder checks for a compatible Windows App Runtime 1.8 framework and downloads Microsoft's runtime installer when the required framework is missing.

App Installer repair

If needed, Melder downloads Microsoft's Desktop App Installer package from the official winget-cli GitHub release and verifies the installed package afterward.

WinGet source recovery

The script includes source update/repair logic and installer retry handling for package-manager failures and hash-mismatch scenarios.

The included Read Me identifies Microsoft sources for App Installer, Microsoft UI Xaml, Microsoft VCLibs, and Windows App Runtime. Melder requires an internet connection for package searches and most installations.

Application Installation

Curated installs plus manual vendor flows

Many selections are installed through WinGet, while other software uses vendor downloads, portable archives, Microsoft Store packages, or an official webpage when a fully automated installation is not appropriate.

WinGet installs

Melder maps a large set of checkboxes to package IDs and installs the selected packages through Windows Package Manager.

Direct and portable installers

Some tools use vendor URLs, GitHub release assets, ZIP extraction, custom install folders, or special verification logic when no standard WinGet flow fits.

Manual download steps

Current examples include NVIDIA App, AMD Software, and some security/vendor products. Melder opens the official website, explains what to do, and waits for Enter before continuing.

Clean cancellation

Manual prompts support qq so the user can stop the RUN sequence instead of being forced to continue.

Gaming

Install games and launchers to a selected drive

When multiple internal drives are available, Melder can ask which drive should be used for supported game, launcher, mod, and emulator installations. If C: is the only eligible internal drive, it can use it automatically where the package allows.

Battle.net is treated specially because its WinGet manifest requires an installation location. Other supported game packages can use their normal default location when appropriate.

Search

Search, install, and uninstall WinGet packages

The Search tab runs WinGet asynchronously so the GUI does not have to block while results are collected. It supports searching the catalog, searching installed packages, listing all installed packages, installing the selected result, and uninstalling a selected installed package.

Catalog Search

Enter a term to search available WinGet and Store-backed results using the currently configured package sources.

Installed Search

Search the packages already installed on the PC or list the entire WinGet-visible installed package inventory.

Tasks

Windows setup and maintenance actions

The Tasks tab groups Windows changes into Disable, Enable, Shortcuts, System Prep, and Uninstall sections.

Disable

Selections include Animations, Encryption, Highlights, Notifications, Sleep, Snap Windows, Suggestions, Task View, Telemetry, Transparency, Widgets, and Xbox Services.

Enable

Selections include Accent Color, Classic Context Menu, Clipboard History, Dark Mode, File Extensions, Hidden Files, Left Taskbar alignment, Night Light, Show Seconds, and automatic time-zone behavior.

Shortcuts

Melder can create desktop web shortcuts for sites such as Amazon, Best Buy, Gmail, Google, Reddit, Yahoo, YouTube, X, and others, plus selected software/project shortcuts.

System Prep

Current selections include App Updates, Auto Restart, Auto Time Zone, Cleanup, Restore Point, Windows Updates, and Select All.

Bloatware

Selective Windows 10/11 app removal

The current Bloatware task uses a curated list of optional Microsoft consumer/inbox apps instead of removing Windows apps indiscriminately. Core utilities and dependencies are intentionally preserved.

Microsoft targets

Examples include Clipchamp, Copilot, Feedback Hub, Maps, Phone Link, consumer Teams, Outlook for Windows, Solitaire, selected legacy Bing packages, and Xbox front-end/overlay packages.

Provisioned promotional apps

Third-party promotional packages such as Amazon, Netflix, Spotify, TikTok, Candy Crush, Instagram, WinZip, and similar apps are only added to the target set when Windows/OEM provisioned them.

Preserved Windows components

Microsoft Store, App Installer, Calculator, Camera, Snipping Tool, Notepad, Terminal, Photos, Sticky Notes, Quick Assist, Web Experience, Cross Device, Gaming Services, and other core dependencies are intentionally retained.

Installed + provisioned cleanup

Matching removable Appx packages can be removed for all users and matching provisioned packages can be removed from the online Windows image for future profiles.

Uninstall Tasks

Selected removal tools

McAfee MCPR

Melder downloads MCPR from McAfee, verifies its Authenticode signature, launches the interactive removal tool, and tells the user to close MCPR rather than click its Restart button when finished.

OneDrive

Melder first tries WinGet uninstall for Microsoft OneDrive and can fall back to the Windows OneDriveSetup uninstall path when necessary.

How To Use

Running Melder

  1. Download and extract Melder.zip.
  2. Run Run Me.bat.
  3. Approve the Windows UAC prompt. The launcher starts PowerShell with -ExecutionPolicy Bypass.
  4. If App Installer or required frameworks are missing/outdated, allow Melder to repair its dependencies.
  5. Review the tabs and check only the apps or tasks you want.
  6. Use the Search tab directly when you want to search, install, or uninstall a package outside the curated lists.
  7. Open the Tasks tab and click RUN to process the selected checkboxes.
  8. When a vendor requires a manual web download, follow the on-screen instructions, then press Enter to continue or type qq to stop cleanly.

Transparency

What Melder can change

Melder is intentionally a system-management utility, so its actions are more powerful than a simple downloader. Depending on your selections, it can install and uninstall applications, modify registry values and Windows services, open Settings pages, create shortcuts, run cleanup/update operations, create a restore point, change taskbar or Explorer preferences, and remove selected Appx packages.

Nothing is meant to run merely because it appears on a tab. The script checks checkbox state before acting. Review all selected items before RUN, especially Windows tweaks, uninstall choices, cleanup, and bloatware removal.

FAQ

Frequently asked questions

Does Melder require the internet?

Yes. The included Read Me explicitly requires an internet connection because package searches, WinGet installs, vendor downloads, and dependency repair rely on online sources.

Does every app install through WinGet?

No. Many do, but Melder also uses direct vendor downloads, GitHub releases, portable ZIPs, Store/AppX packages, and manual official-website flows where appropriate.

Can I install something that is not in the checkbox lists?

Yes. The Search tab can search WinGet directly and install the selected result.

Can Melder uninstall applications?

Yes. The Search tab can uninstall a selected WinGet-visible package, and the Tasks tab includes selected uninstall actions such as Bloatware, McAfee, and OneDrive.

Does Bloatware remove core Windows apps?

The current curated list intentionally preserves core utilities and dependencies including Store, App Installer, Calculator, Camera, Snipping Tool, Notepad, Terminal, Photos, Sticky Notes, Quick Assist, Web Experience, Cross Device, and Gaming Services.

Can I stop during a manual installation step?

Yes. Manual prompts support qq to stop the RUN sequence cleanly.
