Windows Information Utility

System Info

System Info is a free Windows PowerShell utility that creates a local Desktop results folder containing a readable hardware and Windows inventory plus a Windows battery report.

Collected Information

Windows and hardware inventory

The script uses Windows WMI classes to gather a compact set of system details and writes them into one text file.

Operating System

Records the Windows caption, version, and operating-system architecture.

Computer Manufacturer & Model

Reads the system manufacturer and model from Win32_ComputerSystem.

System Serial Number

Records the system serial number exposed through Win32_BIOS.

Motherboard

Records motherboard manufacturer, product/model, and motherboard serial number.

BIOS

Records the BIOS manufacturer and SMBIOS BIOS version.

Network Adapters

Includes IP-enabled network adapters, their descriptions, and the IP address values returned by Windows.

CPU

Records processor name and reported maximum clock speed in MHz.

GPU

Records the names returned by the Windows video-controller inventory.

RAM

Adds the capacities of all physical-memory modules for a total in GB and reports the minimum module speed returned by Windows.

Storage

Lists fixed logical drives with drive letter, volume name, total size, free space, and the script's attempted drive-type classification.

Storage Detail

Drive size, free space, and type

Fixed logical disks are collected from Win32_LogicalDisk where DriveType equals 3. Total and free space are converted to GB and rounded to two decimal places.

Drive-type limitation: the current SSD/HDD helper compares logical drive letters such as C: against Win32_DiskDrive.DeviceID. Those WMI identifiers normally use physical-disk names instead of drive letters, so the current Drive Type value may be inaccurate and can be reported as HDD even when the underlying storage is an SSD.

Output

System Info Results folder

The script uses [Environment]::GetFolderPath("Desktop") and creates a folder named System Info Results if it does not already exist.

System information

Desktop\System Info Results\System Info.txt

Windows battery report

Desktop\System Info Results\battery-report.html
If the System Info Results folder already exists, the script reuses it. System Info.txt is opened for writing, so a new run replaces the previous text report at that location.

Battery

Windows powercfg battery report

At the end of the run, System Info executes:

powercfg /batteryreport /output "...System Info Results\battery-report.html"

The HTML report is generated by Windows itself through powercfg. On battery-equipped systems it can contain battery identification, design/full-charge capacity, recent usage, capacity history, and related battery statistics exposed by Windows.

The command is attempted regardless of whether the computer is a laptop. On a system without a battery, Windows may be unable to provide meaningful battery information.

How To Run

Launching System Info

  1. Download and extract System Info.zip.
  2. Run Run Me.bat.
  3. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC.
  4. The System Info Results folder is created on the current user's Desktop if necessary.
  5. Windows, computer, BIOS, motherboard, network, CPU, GPU, RAM, and storage information are collected.
  6. The information is written to System Info.txt.
  7. Windows powercfg is asked to create battery-report.html in the same folder.
The included Read Me notes that Windows 11 may display a “Windows protected your PC” SmartScreen message because the script was downloaded. Review the files before choosing “More info” and “Run anyway.”

Transparency

What the script does not do

No network requests

The current PowerShell script contains no web request, API request, upload, or download logic.

No software installation

It does not install applications, drivers, modules, or third-party diagnostic tools.

No Windows configuration changes

The script reads system information and writes report files. It does not modify services, registry settings, startup entries, or Windows preferences.

No persistent background component

It does not create a scheduled task, service, startup item, or always-running process.

FAQ

Frequently asked questions

Where are the reports saved?

In a System Info Results folder on the current user's Desktop.

What is saved in System Info.txt?

Windows version/architecture, manufacturer/model, system serial number, motherboard, BIOS, IP-enabled network adapters, CPU, GPU, RAM, and fixed-drive information.

Does it create a battery report?

Yes. It calls Windows powercfg /batteryreport and targets battery-report.html in the same results folder.

Is the HDD/SSD label always accurate?

No. The current lookup method does not correctly map logical drive letters to physical-disk device IDs, so the reported type should not be treated as authoritative.

Does it send my hardware information anywhere?

No. The current script contains no network or upload functionality.

Does it change Windows settings?

No. Its primary actions are reading system information and writing the two local report files.
