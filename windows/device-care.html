Windows Combo Utility

Device Care

Device Care combines Maintenance and Threat Inspection into a single workflow. It downloads the current versions from GitHub, collects the Deep Scan choice before maintenance starts, and coordinates a restart so both HTML reports can be reviewed after signing in.

Included Tools

Two utilities, one workflow

Maintenance

Runs the interactive startup and software checks first, followed by the maintenance operations supported by the current release. Learn more about Maintenance →

Threat Inspection

Runs the security inspection using the previously selected Deep Scan option, without opening its report immediately. Learn more about Threat Inspection →

Current downloads

Device Care retrieves the current component packages from GitHub instead of bundling fixed copies of both tools.

Compatibility checks

The combined workflow checks downloaded scripts for compatible integration points before proceeding.

Reports & Cleanup

After the restart

HTML reporting

Device Care is designed to open both the Maintenance and Threat Inspection HTML reports after Windows sign-in and post-restart processing.

Report links

The Threat Inspection report-link helper is preserved during temporary-file cleanup and uses a fixed filename to avoid accumulating copies.

Downloads cleanup

The workflow attempts to remove eligible Device Care ZIP and extracted folder items in Downloads using 24-hour safeguards.

Separate reports

Maintenance and Threat Inspection remain separate tools and generate their own reports.

How To Run

Launching Device Care

  1. Save open work and ensure the PC has an internet connection.
  2. Download and extract Device Care.zip.
  3. Run Run Me.bat and approve administrator access.
  4. Choose whether to perform a Deep Scan.
  5. Complete the interactive Maintenance prompts.
  6. Allow Maintenance and Threat Inspection to finish and the PC to restart.
  7. Sign back in and review both HTML reports.

FAQ

Frequently asked questions

Do I need to download both individual tools first?

No. Device Care downloads the current component packages when it runs.

When is the Deep Scan question asked?

Before Maintenance begins, so the choice can be reused during Threat Inspection.

Will Device Care restart my computer?

Yes, the intended workflow restarts after both tools finish successfully. Save your work beforehand.

Is Threat Inspection an antivirus replacement?

No. It is a technician inspection tool intended to identify items for review, not replace antivirus protection.

Can I still run either tool separately?

Yes. Maintenance and Threat Inspection remain available independently in the Windows downloads table.

What if a downloaded script changes?

Compatibility checks may stop the workflow if a component no longer supports the expected integration.
