Windows Printing Utility

Print Spooler Fix

Print Spooler Fix is a lightweight PowerShell utility for clearing a stuck Windows print queue. It stops the Print Spooler service, deletes the queued spool-job files, and starts the service again.

Workflow

Three repair steps

01Stop Spooler
02Clear Queue Files
03Start Spooler

Print Spooler

Stops the service before clearing the queue

The script first runs Stop-Service -Name Spooler. Stopping the service releases the active Windows print-spooler files so the queued jobs can be removed.

Queue Cleanup

Deletes queued SHD and SPL files

Once the Spooler is stopped, Print Spooler Fix removes two Windows spool-file types from the printer spool directory:

.SHD files

The script deletes %WINDIR%\System32\spool\printers\*.shd. These shadow files contain print-job metadata used by the Windows spooler.

.SPL files

It also deletes %WINDIR%\System32\spool\printers\*.spl, which contain spooled print-job data waiting to be sent to a printer.

The current script does not select an individual printer or job. It deletes every matching .shd and .spl file in the Windows printer-spool folder, so all queued jobs are cleared together.

Service Restart

Starts printing services again

After the queue files are removed, the script runs Start-Service -Name Spooler. It then prints a completion message and waits for Enter before the PowerShell window closes.

When To Use It

Common stuck-print-queue symptoms

Job will not delete

A document remains in the Windows print queue even after you try to cancel it.

New jobs will not print

A stuck earlier job prevents later documents from progressing through the queue.

Queue shows “Deleting” indefinitely

The spooler may be holding onto a damaged or incomplete job that does not clear normally.

Restarting the printer did not help

If the problem is inside the Windows spool queue rather than the physical printer, clearing the queue can provide a clean starting point.

How To Run

Launching Print Spooler Fix

  1. Download and extract Print Spooler Fix.zip.
  2. Run Run Me.bat.
  3. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC.
  4. The Print Spooler service is stopped.
  5. Queued .shd and .spl print-job files are deleted.
  6. The Print Spooler service is started again.
  7. Press Enter after the completion message to exit.
The included Read Me notes that Windows 11 may display a “Windows protected your PC” SmartScreen message because the script was downloaded. Review the files before choosing “More info” and “Run anyway.”

Transparency

What the current script does not do

No printer-driver reinstall

The script does not install, remove, or update printer drivers.

No printer removal

It does not remove configured printers from Windows.

No network access

The PowerShell script contains no download, upload, API, or other network communication.

No permanent service change

The Spooler is stopped temporarily for cleanup and then started again. The script does not change its startup type.

FAQ

Frequently asked questions

Will this delete every queued print job?

Yes. The current script deletes all matching .shd and .spl files from the Windows printer-spool directory.

Will it remove my printer?

No. Configured printers are not deleted.

Will it reinstall my printer driver?

No. This utility only resets the active print queue by stopping the Spooler, deleting queued-job files, and starting the Spooler again.

Does it require administrator access?

Yes. The included batch launcher requests elevation through UAC.

Does the Print Spooler stay disabled?

No. The script starts the Spooler again immediately after clearing the queue files.

Does it send printer information anywhere?

No. The current script contains no network or upload functionality.
