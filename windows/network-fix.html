Windows Network Utility

Network Fix

Network Fix is a free Windows PowerShell utility that tests basic internet connectivity, resets common Windows network components, launches DNS Jumper for interactive DNS testing, reports the active IPv4 DNS servers, runs Ookla Speedtest, and saves the complete console session to a local transcript.

Connectivity

Initial network test

Network Fix starts by sending one ICMP test with PowerShell Test-Connection to 8.8.8.8. When a response is received, the script prints the responding address and measured response time in milliseconds.

This first check tests reachability to the specified IP address. Because it uses an IP address directly, this particular test does not depend on DNS name resolution.

Network Reset

Windows networking commands

The next stage runs a group of built-in Windows networking commands intended to refresh DHCP/DNS state and reset core networking components.

Release IP address

Runs ipconfig /release and reports that the IP address was released.

Flush DNS cache

Runs ipconfig /flushdns to clear the local Windows DNS resolver cache.

Renew IP address

Runs ipconfig /renew to request renewed DHCP configuration.

Reset TCP/IP

Runs netsh int ip reset to reset Windows TCP/IP configuration.

Reset Winsock

Runs netsh winsock reset to reset the Winsock catalog.

Continues after errors

The network-reset block is wrapped in PowerShell error handling so an exception can be reported instead of ending the entire script.

These commands actively change Windows network state. Releasing/renewing an address can temporarily interrupt connectivity, and Windows may require a restart before every reset fully takes effect.

DNS Jumper

Interactive DNS testing

Network Fix downloads DnsJumper.zip to the current user's temporary folder from customresolutionutility.b-cdn.net, extracts it under %TEMP%\DnsJumper, and launches DnsJumper.exe.

  1. Network Fix opens DNS Jumper and waits for it to close.
  2. The script instructs you to choose Fastest DNS.
  3. Select Start DNS Test.
  4. Select Apply DNS Server if you want to use the chosen result.
  5. Exit DNS Jumper so Network Fix can continue.
DNS Jumper is a separate utility downloaded at runtime. The current Network Fix script does not perform a digital-signature or checksum verification on that downloaded ZIP before launching the extracted executable.

DNS Report

Current IPv4 DNS servers

After DNS Jumper closes, Network Fix queries Windows with Get-DnsClientServerAddress -AddressFamily IPv4. It takes the first adapter entry that contains server addresses and reports its first DNS server as Preferred DNS and its second server, when present, as Alternate DNS.

Because the current script selects only the first matching DNS-client entry, this section is a quick summary rather than a complete per-adapter DNS inventory.

Temporary Files

DNS Jumper cleanup

After the DNS stage, Network Fix deletes both the downloaded DnsJumper.zip and the extracted %TEMP%\DnsJumper folder with PowerShell Remove-Item.

Speedtest

Ookla Speedtest installation and run

Checks for Speedtest

The script checks for an Appx package match and, as a fallback, whether a speedtest command is already available in the current PATH.

Installs with WinGet when needed

If Speedtest is not detected, Network Fix runs WinGet with package ID Speedtest.Ookla and accepts the package/source agreements.

Runs inline

The script launches speedtest --accept-license --accept-gdpr so Ookla's command-line results are displayed directly in the PowerShell session.

Results are captured

Because PowerShell transcription is active, the Speedtest output is included in the same local NetworkFix.txt transcript as the other stages.

Saved Results

NetworkFix.txt

Network Fix starts a PowerShell transcript before performing its tests and repairs. The transcript is appended to NetworkFix.txt in the directory containing the script. If PowerShell cannot determine that directory, the script falls back to the current user's profile folder.

Because Start-Transcript uses -Append, running Network Fix again can add a new session to an existing NetworkFix.txt instead of automatically replacing the previous transcript.

How To Run

Launching Network Fix

  1. Download and extract Network Fix.zip.
  2. Run Run Me.bat.
  3. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC.
  4. Allow the connectivity test and Windows network-reset commands to complete.
  5. Follow the on-screen DNS Jumper instructions, then close DNS Jumper.
  6. Network Fix reports the detected IPv4 DNS server addresses.
  7. The temporary DNS Jumper files are removed.
  8. Ookla Speedtest is checked/installed and then run.
  9. The transcript is stopped and its saved path is displayed.
The included Read Me notes that Windows 11 may display a “Windows protected your PC” SmartScreen message because the script was downloaded. Review the files before choosing “More info” and “Run anyway.”

DNS Jumper download

https://customresolutionutility.b-cdn.net/DnsJumper.zip is used to download DNS Jumper into the user's temporary folder.

WinGet / Ookla

The script can use Windows Package Manager to install package Speedtest.Ookla and then executes its command-line Speedtest client.

Local transcript

The script saves console activity to NetworkFix.txt. It contains no separate command that uploads the transcript to Melding Software.

FAQ

Frequently asked questions

Does Network Fix change my network settings?

Yes. It releases and renews IP configuration, flushes DNS, resets TCP/IP, resets Winsock, and DNS Jumper can change the configured DNS server if you choose Apply DNS Server.

Does it require the internet?

Yes. The connectivity test, DNS Jumper download, WinGet installation, and Speedtest stages rely on network access.

Does it automatically choose my DNS server?

No. DNS Jumper is interactive. Network Fix tells you to run the fastest-DNS test and apply the result yourself.

Does it keep DNS Jumper installed?

No. The ZIP and extracted temporary DNS Jumper folder are deleted after that stage completes.

Where are the results saved?

Normally to NetworkFix.txt in the same directory as Network Fix.ps1.

Will previous results be overwritten?

Not necessarily. The current script starts the transcript with -Append, so a later run can be appended to the existing NetworkFix.txt.
