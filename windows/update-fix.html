Windows Update Repair Utility

Update Fix

Update Fix is a free Windows PowerShell utility for troubleshooting Windows Update download and servicing problems. It resets core update services and cache folders, repairs the Windows component store with DISM, runs System File Checker, and starts the services again.

Workflow

Four major repair stages

01Stop Services
02Clear Update Folders
03DISM + SFC
04Start Services

Services

Stops Windows Update-related services

Before deleting update working folders, the script attempts to stop four Windows services with PowerShell Stop-Service -Force.

wuauserv

The Windows Update service, which manages detection, download, and installation of Windows updates.

cryptSvc

Cryptographic Services, used by Windows for catalog databases, signatures, and related servicing operations.

BITS

Background Intelligent Transfer Service, used by Windows and other software for background file transfers.

msiserver

The Windows Installer service, which can participate in software installation and servicing workflows.

Each stop/start operation is wrapped in a try/catch block. A service failure is printed in red, and the script continues to the next service.

Update Cache Reset

Deletes SoftwareDistribution and catroot2

SoftwareDistribution

The script recursively removes C:\Windows\SoftwareDistribution, which Windows Update uses for downloaded update files and update working data.

catroot2

It also recursively removes C:\Windows\System32\catroot2, which is used by Windows servicing and update catalog processing.

Both deletions use -ErrorAction SilentlyContinue. That means the script prints its general folder-deletion completion message even if some files or folders could not be removed.

DISM

Component-store cleanup and repair

StartComponentCleanup

Runs DISM /Online /Cleanup-Image /StartComponentCleanup to clean superseded Windows component-store content.

ScanHealth

Runs DISM /Online /Cleanup-Image /ScanHealth to scan the Windows component store for corruption.

RestoreHealth

Runs DISM /Online /Cleanup-Image /RestoreHealth to repair detected component-store corruption.

Runs sequentially

The current script waits for each console command to finish before moving to the next stage.

System File Checker

SFC /scannow

After DISM completes, Update Fix runs sfc /scannow. System File Checker verifies protected Windows system files and attempts to repair damaged copies using the Windows servicing infrastructure.

Service Recovery

Starts the services again

The script loops through the same four service names and attempts to start each one with Start-Service. Individual startup failures are reported while the script continues processing the remaining services.

How To Run

Launching Update Fix

  1. Download and extract Update Fix.zip.
  2. Run Run Me.bat.
  3. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC.
  4. The four Windows Update-related services are stopped.
  5. SoftwareDistribution and catroot2 are deleted.
  6. DISM StartComponentCleanup, ScanHealth, and RestoreHealth run.
  7. sfc /scannow runs.
  8. The four services are started again.
  9. Press Enter to close the PowerShell window.
The included Read Me notes that Windows 11 may display a “Windows protected your PC” SmartScreen message because the script was downloaded. Review the files before choosing “More info” and “Run anyway.”

If Problems Continue

Repair-install guidance from the included Read Me

The Read Me recommends using Microsoft's Windows 10/11 Installation Assistant or installation-media tools if Windows Update problems continue, with the goal of keeping files and apps while installing the latest Windows version/updates.

Transparency

What the current script does and does not do

Actively resets update state

This is not a read-only diagnostic. It stops services, deletes Windows Update working folders, performs component-store servicing, and can repair protected system files.

No third-party repair software

The repair operations use built-in Windows services, DISM, SFC, and PowerShell commands.

No direct web downloads

The current PowerShell script does not contain Invoke-WebRequest, Invoke-RestMethod, or another explicit downloader.

No automatic reboot

The script does not restart Windows automatically after completing the repair sequence.

FAQ

Frequently asked questions

What Windows Update services are reset?

wuauserv, cryptSvc, bits, and msiserver.

What folders are deleted?

C:\Windows\SoftwareDistribution and C:\Windows\System32\catroot2.

What DISM commands are used?

StartComponentCleanup, ScanHealth, and RestoreHealth.

Does it also run SFC?

Yes. sfc /scannow runs after the DISM commands.

Does it require administrator access?

Yes. The included batch launcher elevates PowerShell through UAC.

Will it reboot the PC?

No. The current script contains no automatic restart command.
