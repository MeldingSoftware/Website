Windows Repair Utility

Repair Tool

Repair Tool is a focused Windows PowerShell utility that runs Microsoft DISM component-store analysis, cleanup, health checks, and repair commands, then runs System File Checker to verify and repair protected Windows system files.

Repair Sequence

DISM first, SFC second

The script runs the servicing commands in a fixed order so the Windows component store is analyzed and repaired before System File Checker performs its final protected-file scan.

01Analyze & Clean
02Check, Scan & Restore
03SFC /scannow

DISM

Windows component-store servicing

Analyze Component Store

Runs DISM /Online /Cleanup-Image /AnalyzeComponentStore /NoRestart to analyze the Windows component store and report its servicing/cleanup state.

Start Component Cleanup

Runs DISM /Online /Cleanup-Image /StartComponentCleanup to clean superseded component-store content through Microsoft's servicing stack.

CheckHealth

Runs DISM /Online /Cleanup-Image /CheckHealth for a quick check of whether Windows has already marked the component image as corrupted.

ScanHealth

Runs DISM /Online /Cleanup-Image /ScanHealth to perform a deeper component-store corruption scan.

RestoreHealth

Runs DISM /Online /Cleanup-Image /RestoreHealth to repair component-store corruption when Windows detects it.

No automatic reboot command

The current PowerShell script does not issue a restart command after DISM or SFC completes.

The included Read Me marks Repair Tool as requiring internet access. The script itself does not directly download files with PowerShell, but DISM RestoreHealth can rely on Windows-configured repair sources when replacement components are needed.

System File Checker

SFC /scannow

After all DISM commands finish, Repair Tool runs sfc /scannow. System File Checker verifies protected Windows system files and attempts to replace corrupted copies using the Windows servicing infrastructure.

Saved Results

Repair Tool Results\DISM_SFC.txt

Before the repair commands start, Repair Tool creates a results folder and starts a PowerShell transcript so the console output is saved for later review.

Normal Desktop

If %USERPROFILE%\Desktop exists, the output folder is created as Desktop\Repair Tool Results.

OneDrive Desktop fallback

If that Desktop path is not found, the script uses %USERPROFILE%\OneDrive\Desktop\Repair Tool Results.

Transcript file

The full PowerShell transcript is written to DISM_SFC.txt inside the Repair Tool Results folder.

Transcript closes cleanly

After SFC finishes, the script prints its completion message and stops the PowerShell transcript before waiting for Enter.

How To Run

Launching Repair Tool

  1. Connect the PC to the internet, as recommended by the included Read Me.
  2. Download and extract Repair Tool.zip.
  3. Run Run Me.bat.
  4. The launcher starts PowerShell with -ExecutionPolicy Bypass and requests administrator elevation through UAC.
  5. Repair Tool creates the local results folder and starts its transcript.
  6. DISM AnalyzeComponentStore runs.
  7. DISM StartComponentCleanup runs.
  8. DISM CheckHealth, ScanHealth, and RestoreHealth run in sequence.
  9. sfc /scannow runs last.
  10. Review DISM_SFC.txt in the Repair Tool Results folder for the saved output.
  11. Press Enter to close the PowerShell window.
The included Read Me notes that Windows 11 may display a “Windows protected your PC” SmartScreen message because the script was downloaded. Review the files before choosing “More info” and “Run anyway.”

Transparency

What Repair Tool changes

Windows component servicing

DISM StartComponentCleanup and RestoreHealth can change the Windows component store as part of Microsoft's built-in servicing process.

Protected system-file repair

SFC can replace corrupted protected Windows system files when valid repair copies are available.

No third-party repair software

The current script relies on built-in Microsoft Windows DISM and SFC executables rather than downloading a third-party repair application.

No data upload

The current PowerShell script contains no upload/API command for sending the saved DISM/SFC transcript to Melding Software or another service.

FAQ

Frequently asked questions

What does Repair Tool actually run?

DISM AnalyzeComponentStore, StartComponentCleanup, CheckHealth, ScanHealth, RestoreHealth, and finally sfc /scannow.

Does it require administrator access?

Yes. The batch launcher requests an elevated PowerShell window through UAC.

Where are the results saved?

Normally under Desktop\Repair Tool Results\DISM_SFC.txt, with a OneDrive Desktop fallback when the regular Desktop path is not present.

Does it restart Windows automatically?

No. The current script does not contain an automatic reboot command.

Does it use third-party repair software?

No. The repair operations use Microsoft's built-in DISM and System File Checker tools.

Why does the Read Me say internet is required?

The script itself does not issue a direct web download, but DISM RestoreHealth may need access to a Windows repair source when replacement components are required.
